—
加密：AES-256-GCM，主密钥 /opt/llama-panel/master.key（32 字节随机 · 0600 · 仅 root 可读）。 保存后优先于上面的「密钥路径」。

运行身份

—
—
非 root 模式会创建专用用户 llama-panel、把状态移到 /var/lib/llama-panel、 并把 /opt/llama-panel 收紧为 root 所有（堵掉「替换二进制」这条本地提权路径）。 只有 5 类写操作经 helper 提权。切换后面板会重启，若起不来会自动回滚到 root。
